# Personal Portfolio Website

A responsive personal portfolio website showcasing my skills, projects, and contact details. Built with HTML, CSS, and vanilla JavaScript.

##  About This Project

This is **Task 1 (Personal Portfolio Website)** of the Full Stack Development Internship at Auspify Technologies. It covers layout design, four responsive pages (Home, About, Projects, Contact), a project showcase section, and deployment.

##  Live Demo

[Visit Portfolio](https://starlit-halva-dee3ac.netlify.app/)

##  Features

- **Responsive Design** - Works on mobile, tablet, and desktop
- **Clean UI** - Minimalist layout with smooth animations
- **Project Showcase** - Interactive carousel to browse projects
- **Contact Form** - Form with client-side validation and a confirmation message
- **Semantic HTML** - Structured, readable markup

##  Pages

### Home (`index.html`)
- Hero section with introduction
- Profile image
- Call-to-action buttons for navigation

### About (`about.html`)
- Personal bio
- Tech stack
- Languages spoken
- Interests and hobbies

### Projects (`projects.html`)
- Interactive carousel of projects
- Project descriptions and technology tags
- Navigation indicators

### Contact (`contact.html`)
- Contact information
- Email and social links
- Contact form with validation

##  Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Flexbox, Grid, animations, media queries
- **JavaScript (Vanilla)** - Carousel and form validation
- **Canva** - Design assets

##  Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Swati-Vishwa/Personal-portfolio-1
   cd Personal-portfolio-1
   ```

2. **Open in your browser**
   - Double-click `index.html`, or
   - Use the **Live Server** extension in VS Code (right-click `index.html` → *Open with Live Server*)

No build step or dependencies are required.

##  Responsive Breakpoints

- **Desktop** - 1200px and above
- **Tablet** - 768px to 1199px
- **Mobile** - 480px to 767px
- **Small Mobile** - Below 480px
